# Официальные эмблемы АСБ

Проверено 5 ноября 2026 года. В `asb-team-logos.json` сохранены 54 точных
идентификатора АСБ, варианты названий из таблиц и сеток, реальная идентичность
из `Widget/TeamInfo`, адрес файла и официальный `TeamGames`, связывающий эмблему
с конкретной командой. Одноимённые КГУ из Калуги и Курска, мужские и женские
составы сопоставляются отдельно.

## Причины пропусков

- `Widget/CompTeamResults` вообще не публикует эмблемы: у всех 124 строк
  исходного манифеста `team_logo_url` был `null`.
- Старые матчи часто возвращают `https://img.infobasket.su/logo/0.png`:
  это общая заглушка, а не эмблема команды. Для части команд настоящая эмблема
  находится в их собственном `TeamGames`, включая женские ВГМУ и ВГТУ-ф.
- `files.infobasket.su/Logos/` и `img.infobasket.su/logo/` используют разные
  идентификаторы файлов. Переписывание домена ломает ссылки: например,
  `files/.../17024.png` существует, `img/.../17024.png` возвращает 404;
  для `21494.png` верно обратное.
- Официальные PNG ВГАУ (16492 и 16493) содержат неверную контрольную сумму
  метаданных iCCP. Данные изображения и их CRC корректны. Скрипт удаляет
  вспомогательные метаданные перед декодированием и создаёт чистый WebP.

## Локальный кэш

46 проверенных файлов WebP (около 1,6 МБ вместе с индексом) включены в пакет
backend: `src/predatory_beavers/modules/standings/assets/logos/`.
Индекс содержит точные идентичности, допустимые имена, источники и SHA-256.
Обработчик выдаёт только известный файл с совпадающей контрольной суммой;
во время пользовательского запроса сеть не используется.

Функции `team_logo_path(external_team_id, team_name)` и `get_logo_path(key)`
возвращают локальный URL `/api/v1/standings/logos/{key}.webp` и проверенный путь.
Без точного ID и проверенного имени эмблема не подставляется.

Покрытие: 115 из 124 строк таблиц и 169 из 182 сторон матчей плей-офф.
Оставшиеся 8 идентичностей публикуют только официальную заглушку:

| ID | Команда | Регион |

| 6870 | ВГТУ-Ф | Воронеж |
| 7429 | КФ МГТУ | Калуга |
| 7585 | ЛГТУ (женщины) | Липецк |

| 20589 | ВГИФК-ф / ВГАС-2 | Воронеж |

| 32931 | ВГАС-Ф | Воронеж |
| 54902 | ВФ РГУПС | Воронеж |

Для них интерфейс сохраняет честную буквенную заглушку; чужие эмблемы
по совпавшей аббревиатуре не используются.

Проверка без сети:

```powershell
$env:PYTHONPATH='src'
.venv\Scripts\python.exe scripts/cache_asb_standings_logos.py
```

`--fetch` загружает недостающие файлы только из проверенного манифеста,
`--fetch --refresh` явно обновляет их. Базы данных, статистика и архив
таблиц этим скриптом не меняются.
