# Проверка матчей АСБ — 11 ноября 2026

Проверены обе официальные системы статистики АСБ. Новый сайт
[asbasket.ru](https://asbasket.ru/) использует публичный API Sportoteka;
его адрес подтверждён в загружаемом сайтом JavaScript. У API обязателен
`tag=asb`: запрос без него может вернуть пустую команду или пустой список.

## Текущий сезон 2026/27

Старый официальный указатель
[мужской](https://asb.infobasket.su/Widget/GetTeamComps/7433) и
[женской](https://asb.infobasket.su/Widget/GetTeamComps/7695) команд теперь
называет настоящий идентификатор сезона `56293`. Общий указатель сезонов
всё ещё отдаёт для нового сезона `CompID=0`, поэтому его нельзя использовать
как единственное подтверждение текущего сезона.

Проверены полные календари, включающие завершённые и запланированные игры:

| Команда | Календарь команды | Календарь дивизиона | Опубликовано |
|---|---|---|---:|
| Мужчины, ВГУ, 7433 | [Sportoteka](https://asb.sportoteka.org/api/abc/teams/games?teamId=7433&tag=asb&season=2027&lang=ru&maxResultCount=1000) | [Воронежская область (м)](https://asb.sportoteka.org/api/abc/comps/calendar?tag=asb-cfo-36-m&season=2027&lang=ru&maxResultCount=1000) | 0 |
| Женщины, ВГУ — Хищные бобры, 7695 | [Sportoteka](https://asb.sportoteka.org/api/abc/teams/games?teamId=7695&tag=asb&season=2027&lang=ru&maxResultCount=1000) | [Воронежская область (ж)](https://asb.sportoteka.org/api/abc/comps/calendar?tag=asb-cfo-36-w&season=2027&lang=ru&maxResultCount=1000) | 0 |

В ответах всех четырёх запросов `status=Ok`, `totalCount=0`, `items=[]`.
Это отсутствие опубликованного расписания в проверенных источниках, а не
утверждение об отсутствии команды или соревнований. Предстоящие матчи клуба
не добавлены с предположительными соперниками и датами.

Старый `TeamGames` при запросе сезона 56293 возвращает игры 2025/26.
Сборщик проверяет фактические даты и исключает такой переход на прошлый сезон.

## Подтверждённый архив

Сверены все сезоны известных официальных идентификаторов команды:
мужчины — с 2018/19, женщины — с 2019/20. Всего 162 записи: 148 завершённых
игр и 14 исторических записей без опубликованного результата. Новый API
не добавил отсутствующих в старом архиве GameID. Четыре старые игры 2019 и
2020 года всё ещё имеют upstream-статус `Scheduled`; они не выдаются за
предстоящие и не получают вымышленного результата 0:0.

Дополнительно повторно проверены доступные ветки Воронежской области и
Черноземья сезонов 2016/17 и 2017/18. Региональные таблицы Воронежа пусты,
плей-офф содержит пустые пары, ВГУ не найден в опубликованных таблицах
Черноземья. Ранее отмеченные пробелы старых сезонов сохраняются явно.
Полнота матчей до подтверждённых идентификаторов команды не заявляется.

## Обновление

`scripts/collect_asb_archive.py` объединяет Widget и Sportoteka по `GameID`,
проверяет команду, сезон и отсутствие усечения ответа. При исчезновении ранее
подтверждённых игр сборка останавливается для проверки. Каждая исходная
выгрузка сохраняется с URL и UTC-временем в `data/results-research/asb-games/`;
проверенные URL и время также записаны в `docs/results-asb.json`.

Импортёр сохраняет будущие опубликованные матчи в `archive_results` как
`scheduled`, без счёта. В `matches` добавляются только завершённые игры
с опубликованным временем начала. Матчи с известным только днём остаются
в `archive_results` с точностью `day`. Архивная схема пока хранит расписание
с точностью до дня; опубликованное время сохранено в исходном JSON.
Уже существующие матчи и редакторские правки не перезаписываются. Импорт
применяется к `data/local.db` только после штатной резервной SQLite-копии.

```powershell
.\.venv\Scripts\python.exe scripts/collect_asb_archive.py
.\.venv\Scripts\python.exe scripts/import_public_results.py
.\.venv\Scripts\python.exe scripts/import_public_results.py --apply
```
